# Pocket Casts Android — Demodularized

This is a **demodularized version** of the Pocket Casts Android app, refactored from a modularized architecture into a single monolithic module.  

The purpose of this repository is to **compare build performance** between a fully modularized project and a monolith, providing a practical reference for Android developers interested in the trade-offs of modularization.  

For a full write-up of the comparison and results, see the blog post: [Gradle modularization delivers 3x faster Android builds](https://mobile.blog/2025/09/08/gradle-modularization-delivers-3x-faster-android-builds/).  

> Note: This is for experimental and educational purposes. Not intended for production use.
